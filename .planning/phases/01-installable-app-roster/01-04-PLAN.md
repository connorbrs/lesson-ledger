  <behavior>
    - singleFlight(fn): two calls made before the first settles call fn once and both receive the same result; after it settles a new call runs fn again; a rejection reaches every caller that was waiting and a later call runs fn again
    - isStandalone(win): true when win.matchMedia('(display-mode: standalone)').matches is true; true when win.navigator.standalone is true; false when neither; uses navigator.standalone when matchMedia is missing; never throws
    - ensurePersistence(storage): returns 'not-supported' when storage or its persist or persisted function is missing; calls persist() then persisted() and returns 'granted' when persisted() is true and 'not-granted' when false; returns 'not-granted' (never throws) when persist() rejects; two calls made while one is pending call persist() once and resolve to the same value
    - readUsage(storage, timeoutMs): returns { usage, quota } when estimate() resolves with both numbers; null when estimate is missing, rejects, resolves without both numbers, or has not answered after timeoutMs (default 2000, tested with fake timers)
    - formatBytes(bytes, locale): 0 gives '0 kB', 512000 gives '512 kB', 1200000 gives '1.2 MB', 1500000000 gives '1.5 GB' using Intl.NumberFormat with unit style and decimal (1000-based) thresholds, called with locale 'en'
    - Import boundary: the text of src/pwa/useAppUpdate.ts contains no import from a path containing '/data', no import of 'dexie', and no use of indexedDB

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service worker cache to the running app | The installed app runs whatever build the service worker serves |
| Update prompt to page reload | A reload discards unsaved input |
| Settings to the user | Storage status text informs the user how safe their data is |
| Safari tab to home-screen app | Two contexts the user can confuse |

## STRIDE Threat Register

Threat IDs continue from Plan 03 (T-01-10 to T-01-14); this plan uses T-01-15 to T-01-18 and T-01-SC.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | Tampering | Service worker serving a stale or wrong build | low | mitigate | Prompt-style update with a visibilitychange update check, a Build row to tell builds apart, and the marker-deploy test in Task 4 |
| T-01-16 | Information disclosure | Settings implying protection that does not exist | medium | mitigate | Persistent storage value comes straight from persisted(); the Not granted footer says iOS has not agreed to protect the data; prohibition recorded in must_haves |
| T-01-17 | Denial of service | Update reload destroying unsaved form input | low | mitigate | Updates only on the Update App tap (prohibition); banner copy tells the user to save first; grep gate keeps updateServiceWorker out of the UI |

| T-01-SC | Tampering | npm package installs (supply chain) | high | mitigate | No new packages are installed in this plan; lockfile and `npm ci` unchanged |
