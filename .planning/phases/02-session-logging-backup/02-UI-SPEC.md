### Log form field contract

- **Date row:** label "Date", value "Today" when the date is today, otherwise "Mon, Oct 12". Default is today (local calendar date). Tap opens the native date wheel (`input type="date"`).
- **Start row:** label "Start", value "Not set" (secondary) or "4:30 PM". Optional. Tap opens the native time wheel. When set, a "Clear Start Time" text action sits at the trailing edge.
- **Subject row:** segmented "Swim" | "Math" in one row. Default: last session's subject; else the student's Default Subject (if "Both", Swim).
- **Students row:** label "Students", value the names joined with ", " (secondary, clamped to 2 lines), or "Choose students" (secondary) when none.
- **Minutes rows:** each of Lesson, Activity, Travel is one block:
  - Line 1: label (Body) on the left; numeric field on the right (17px, tabular, right-aligned, suffix "min" in secondary). `inputmode="numeric"`, no spinner. Accepts 0–999 whole numbers.
  - Line 2: segmented "30" | "45" | "60", full width, 32px, 8px above. Tapping a preset sets the value. A typed value equal to a preset selects that segment; any other value clears the selection.
  - Invalid value: caption "Use whole minutes, 0 to 999." (Label, destructive) under line 2; Log Session disabled.
  - Travel footer: "Travel is for your records only. It never appears on family summaries."
- **Defaults:** pre-filled from the last session. With no previous session: Lesson 45, Activity 0, Travel 0.
- **Zero minutes are allowed.** Activity-only sessions (Lesson 0) save. A zero-minute session saves too. Phase 4 warns about it before sending.

### Students picker rules

- **Swim:** up to two students. A third tap is ignored; the footer reads "Swim takes up to two students." Rows that cannot be selected are text-secondary.
- **Math:** exactly one student. Tapping another student replaces the selection. Footer: "Math takes one student. Choosing another replaces this one."
- **Archived students** are never listed.
- **Empty** (no active students): heading and body from the Copywriting Contract; no action button; Back returns to the parent.
- Two students from the same family count once for that family; no credit group appears.

### Credit groups (conditional)

- **Shown only when:** subject is Swim and two students belong to two different families.
- **Layout:** one group per family, in the order students were picked. Header is the family name (Heading). Two rows: "Lesson" and "Activity", each with a Full | Half segmented control on the right. Defaults are Full for both, every session.
- **Footer (Label, secondary):** "Credited: {L} lesson, {A} activity." Example: "Credited: 22.5 min lesson, 30 min activity."
- **Full** = 100% of the entered minutes; **Half** = 50%, exact in storage. Credited minutes display per the Shared hour formatter's minute rule (up to one decimal, trailing ".0" dropped), for example "22.5 min".
- **Students group footer when two families are picked:** "Two families: choose full or half credit for each below."

### Backup reminder (Log tab)

- **Hidden** until the first session exists.
- **Quiet** (0–6 days since last backup): a Label line in secondary text after the form groups (last item in the scroll): "Last backup today" / "Last backup yesterday" / "Last backup 3 days ago".
- **Highlighted** (7+ days, or no backup yet while a session exists): a card (surface, radius 12px, 16px margin, 16px padding) with heading "Back up your data" (Heading), a body line ("Last backup 8 days ago." or "No backup yet."), and a "Back Up Now" accent text action (44px) beneath. It does not compete with the sticky Log Session button; the button is text-only, not filled.
- Day counts use local calendar days. The card is not dismissible.

### Sessions list

- **Period control:** Week | Month segmented (32px). Week runs Mon–Sun. Month is the calendar month. Default is Week, current period.
- **Period label (Heading, centered):** week "Oct 19 – 25" or across months "Oct 27 – Nov 2"; month "October 2026". The year is appended when the period is not in the current year.
- **Accessible labels (not visible):** ‹ reads "Previous week" or "Previous month"; › reads "Next week" or "Next month", following the Week/Month selection.
- **Date groups:** group header = date, Heading, for example "Mon, Oct 19". Each group is a Group with compact rows.
- **Row:**
  - Left (flex, clamped to 2 lines): student names (Body), then a second line (Label, secondary): subject and start time, "Swim · 4:30 PM" or "Swim" when untimed.
  - Right (fixed, right-aligned, Label, tabular): line 1 "Lesson 1.5 h (1:30)" (text primary); line 2 "Activity 0.5 h (0:30)" (text secondary). A zero value reads "Lesson none" or "Activity none". Travel never appears in the row.
  - The right column shows the session's entered minutes (always whole), formatted by the Shared hour formatter. Credited per-family minutes never appear in rows.
  - Row min height 44px; padding 12px 16px; separator inset 16px.
- **Order inside a day:** start time ascending; untimed sessions last, in logging order.

### Edit Session sheet

- Same field groups and rules as the Log form (Session, Students, Minutes, credit groups), with the Student picker pushed inside the sheet.
- Bottom group: one row "Delete Session" (destructive, regular). It sits below all field content and is the only destructive control in the sheet.
- Save is disabled until the form is valid (same rule as Log).

### Settings → Backup group

- **Rows (in order):**
  1. "Last backup": value "Never", "Today", "Yesterday", or "{n} days ago". Not tappable.
  2. "Back Up Now": accent text row. Tap runs the backup flow.
  3. "Restore from Backup…": neutral text row. Tap runs the restore flow.
- **Group footer (default, Label, secondary):** "Backup saves every family, student and session as one file. Restoring replaces everything on this phone."
- **Busy states:** "Back Up Now" reads "Preparing Backup…" (disabled) while the file builds. "Restore from Backup…" reads "Checking Backup…" (disabled) while the file is validated. Replace Everything is disabled while the restore runs.
- **Result line (replaces the default footer until the next visit):** success (secondary) or failure (destructive). No toast.

### Backup flow

1. Build one file with all records (attachments slot present, empty in Phase 2).
2. Open the iOS share sheet (Save to Files / iCloud Drive). If the share API is unavailable, fall back to a download.
3. Completing the share, or the download, sets Last backup to "Today" and clears any failure line.
4. Cancelling the share sheet changes nothing and shows no error.
5. A build failure shows the failure line in the footer: nothing is changed.

### Restore flow

1. Tap "Restore from Backup…" → the native file picker (accepts the backup extension(s) the data layer defines; the picker accepts `.json` and `.zip`). Cancelling the picker does nothing.
2. Row reads "Checking Backup…" while the file is read and validated. Existing data is not touched.
3. **Invalid file → validation alert** (below). Cancel closes; "Choose Another File" reopens the file picker.
4. **Valid file → confirm alert** (below). Cancel closes with nothing changed.
5. **Replace Everything** runs one transaction. Success: result line "Restored. ..." appears in the Backup footer; Log and Sessions update through live queries. Failure: destructive result line; existing data is untouched.

### Sheets, alerts and banners

- **Discard dialog:** title "Discard changes to this session?"; buttons "Keep Editing" (accent) and "Discard Changes" (destructive, 600). Discard writes nothing.
- **Delete alert:** title "Delete this session?"; message "This can't be undone."; buttons "Cancel" (accent, regular) and "Delete Session" (destructive, 600). Delete is disabled while the transaction runs. On failure the message becomes "Couldn't delete this session. Nothing was changed. Try again." and both buttons stay.
- **Save failure** (sheet and Log): "Couldn't save. Your phone may be low on storage. Nothing was changed. Try again." Label, destructive. Sheet stays open with inputs intact. On Log it sits above the Log Session button and the form keeps its values.
- **Restore validation alert:** title "Can't restore this file." Message by cause:
  - Not a backup: "This file isn't a Lesson Ledger backup. Nothing was changed. Choose another file."
  - Damaged: "This backup file is damaged and can't be read. Nothing was changed. Choose another file."
  - Newer version: "This backup was made by a newer version of Lesson Ledger. Update the app, then try again. Nothing was changed."
  Buttons: "Cancel" (accent) and "Choose Another File" (accent, 600).
- **Restore confirm alert:** title "Replace everything with this backup?"; message "Backup from {date}: {F} families, {S} students, {N} sessions. Everything on this phone is replaced. This can't be undone."; buttons "Cancel" (accent) and "Replace Everything" (destructive, 600). Counts use Intl.PluralRules.
- **Alert width:** 272px, as in Phase 1. Long messages wrap; buttons stay 44px.

### Motion and touch

- Phase 1 motion unchanged (push 300ms, sheet 350ms, reduced-motion cross-fade 150ms).
- Segmented selection changes instantly. Period changes replace the list content with a 150ms cross-fade (none under reduced motion, which already uses 150ms fade).
- Pressed-row, text-button and primary-button press states unchanged.

### Layout at 200% zoom

- Log and Sessions reflow to one column. The sticky footer keeps the button at full width. The minutes segmented control stays full width. Verified on device (backstop).

### Shared hour formatter

One formatter serves every hour value: session rows now, and Phase 4 text, PDF and overview totals.

- **Decimal hours:** minutes ÷ 60, rounded half up to 2 decimals, trailing zeros trimmed. Examples: 90 min → "1.5 h"; 60 min → "1 h"; 0 min → "0 h".
- **h:mm:** minutes rounded to the nearest whole minute (half up), then split into hours and two-digit minutes. Example: 22.5 min → 23 → "0:23".
- **Display:** "{decimal} h ({h:mm})". Examples: 90 min → "1.5 h (1:30)"; 22.5 min → "0.38 h (0:23)".
- **Minute values** (credited minutes in the credit footer only): up to one decimal, trailing ".0" dropped. Examples: "22.5 min", "30 min".
- **Stored values stay exact.** Only display rounds. Half credit is never rounded in storage or in the credit math.
- **Session rows** use entered minutes, which are always whole, so they show the decimal and h:mm form with no rounding ambiguity.

Copy rules unchanged: no exclamation marks, no "Oops"; errors state what happened, that nothing was changed, and the next step.

## Assumptions

1. **Lesson default on first run is 45 minutes.** The brief set Activity and Travel to 0 without a previous session; Lesson was not specified. Confirm.
2. **Credit resets to Full for every session.** Credit is not carried forward from the last session.
3. **Subject "Both" falls back to Swim** when a student has Default Subject "Both" and no previous session exists.
4. **Switching to Math with two students selected keeps the first one picked** and drops the second.
5. **Zero-minute sessions save.** Phase 4 handles the warning before sending.
6. **Log Session is a sticky footer above the tab bar**, not a nav-bar action (tab roots have no Save).
7. **Sessions rows are grouped by date.** The date appears as the group header rather than repeated on each row (D-08 intent: date visible, compact rows).
