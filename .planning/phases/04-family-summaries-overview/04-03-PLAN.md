</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-typed message to storage and clipboard | Free text is stored and copied to the system clipboard |
| Edited data to the sent flag | A false negative would let the user believe parents have seen the current hours |
